sequenceDiagram autonumber actor User as Candidate / Recruiter participant UI as React Frontend participant BAP as BAP (Spring Boot) participant QR as Optical QR Engine participant GW as Beckn Gateway participant BPP as Issuer BPP (University) %% Phase 1 Note over User,QR: Phase 1: Upload & Local Authenticity Check User->>UI: Uploads Certificate (PDF/Image) + Consent UI->>BAP: POST /api/candidates/upload BAP->>QR: Scan document with PDFBox & ZXing QR-->>BAP: Extracted QR Payload & Certificate ID BAP-->>UI: Upload Success (Ready for Network Verification) %% Phase 2 Note over UI,BPP: Phase 2: ONEST Decentralized Handshake User->>UI: Clicks "Initiate Verification" UI->>BAP: POST /api/verification/initiate Note over BAP: Sign payload with Ed25519 Private Key BAP->>GW: POST /search (domain: "onest:work-opportunities") GW->>BPP: Broadcast /search BPP-->>GW: ACK (HTTP 200) BPP->>BAP: POST /on_search (Catalog of Issuers) %% Phase 3 Note over BAP,BPP: Phase 3: Contract Finalization BAP->>BPP: POST /init (Candidate Details & Consent Artifact) BPP->>BAP: POST /on_init (Order Terms Initialized) BAP->>BPP: POST /confirm (Final Verification Request) BPP->>BAP: POST /on_confirm (Verified Credential Status) %% Phase 4 Note over UI,BAP: Phase 4: Scoring & Result Presentation BAP->>BAP: Compute score (Capped at 95%) & save audit record loop Poll Status (Every 1s) UI->>BAP: GET /api/verification/status/{id} BAP-->>UI: Return "VERIFIED" + Score + Issuer Details end UI-->>User: Displays Authenticated Badge & Confidence Score
